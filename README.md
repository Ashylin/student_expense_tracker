# Student Expense Tracker
## Project Overview
A Student expense tracking project created using google sheets to analyze daily expenses.
The project allows users to categorize expenses,calculate totals,and visualize spending patterns.

## Tools Used
-Google Sheets(original project for interactive use)
-Microsoft Excel(.xlsx) (sample dataset provided in this repository for reference and dashboard building)

## Features
-Category-wise expense analysis
-Total expense calculation
-Charts for visualization
-Includes a Month column for easy analysis
-Ready for Power BI dashboards

## Note
-This project was originally built using Google sheets,a blank sheet link is available on LinkedIn for interactive use
-The uploaded Excel file is a sample dataset downloaded version for reference and Power BI dashboard creation.
